# Will You Go Out With Me? 💝

A tiny, silly web app that asks someone on a date. It serves absolutely no practical purpose — it was built entirely on a whim, for the fun of it.

---

## What it does

The app walks through three screens:

1. **The big question** — asks *"Will you go out on a date with me?"* The "Maybe later" button runs away from the cursor so it can never be clicked.
2. **The date planner** — collects three things, one step at a time:
   - Where you'd like to go (pick as many spots as you want)
   - When you're free
   - Any special requests
3. **The confirmation** — celebrates with confetti and floating hearts, then shows a summary of the date plan.
